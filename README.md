# CarGarage – Automotive Service Platform

A full-stack web app for a car service garage. Customers book services for their cars online, and the garage manages services, appointments and discount offers.

## Status
Under active development.

## Features
**Customer:** register and log in · manage cars · browse services · book one or more services for a car and date · view and reschedule bookings · view discount offers and facelift kits

**Admin:** manage services · accept, reject or cancel appointments · view customers and their cars · create discount packages with email notifications · manage facelift kits

## Tech stack
- **Backend:** Java 17, Spring Boot, Spring Data JPA, Spring Security (JWT), MySQL
- **Frontend:** React (Vite)
